# Update Project Memory

## When to Use

Вызывай при:
- Добавлен/удалён модуль, сервис, крупный компонент
- Принято архитектурное / дизайн-решение
- Исправлен критический баг, меняющий поведение системы
- Снято или обнаружено известное ограничение
- Смена стека (новая зависимость, удалена библиотека)

НЕ обновлять на тривиальном (CSS, переименования переменных, мелкий рефактор).

## How to Update

1. Обнови `CLAUDE.md` в корне проекта — primary source of truth для Claude Code
2. Если в проекте есть зеркало памяти (`~/.claude/projects/<enc>/memory/`) — синкни его
3. Минимальные точечные правки нужных секций. Не переписывай неизменённые

## Rules

- Один буллет = одно предложение
- Тон и стиль как у существующего контента
- Без таймстампов и ссылок на чат — файл читается как timeless snapshot
- Снял «Known Limitation» (починил) — убери и из future plans
